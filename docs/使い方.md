# 使い方

Salesforce レポートの情報、状態、メモを Excel に貯め、SOQL の下書きを作るツールです。

## 初回準備

1. `config.ini.example` を `config.ini` にコピーする。
2. `[FILES]` の各パスを必要に応じて変更する。
3. `python -m soql_collector --help` で確認する。

`[FILES]` では次のパスを指定できる。

- `MASTER_XLSX_PATH`: `import-master` で読む管理表（省略可）
- `EXCEL_PATH`: レポート情報を蓄積する Excel
- `JSON_DIR`: Describe 原本を保存するディレクトリ
- `CSV_PATH`: `export-csv` の出力先（省略可）

`import-master` と `export-csv` のパスは、CLI 引数、`config.ini` の順に優先する。
どちらにも指定がなければエラーになる。

## 対話メニュー

プロジェクト直下で `python main.py`（または `実行.bat`）を引数なしで実行すると、
番号を選ぶだけの対話メニューが起動する。毎回サブコマンドと引数を打つのが面倒なときはこちらを使う。
表示された番号を入力し、続けて聞かれる項目（URL・状態・メモなど）を入力すると、下の
`python -m soql_collector ...` と同じ処理が実行される。空Enterで省略可能な項目を飛ばせる。
`0` かそのままEnterでメニューを終了する。

## 基本操作

```powershell
python -m soql_collector import-master .\管理表.xlsx
python -m soql_collector collect --master
python -m soql_collector list --status REVIEW
python -m soql_collector show 00O...
python -m soql_collector note 00O... 確認担当へ照会中
python -m soql_collector mark 00O... BLOCKED
python -m soql_collector confirm-mapping Site Account ACCOUNT.NAME Name string
python -m soql_collector build-soql 00O... --apply
python -m soql_collector export-csv .\output\soql_drafts.csv
```

`config.ini` に `MASTER_XLSX_PATH` / `CSV_PATH` を設定している場合は、次のように
パス引数を省略できる。

```powershell
python -m soql_collector import-master
python -m soql_collector export-csv
```

`collect --dry-run` は接続・保存をしない。複雑なレポートは JSON 原本と備考を見て
手動で組み立てる。実行前に対象 Excel を閉じる。
