# 仕様書

## 1. 目的

Salesforce レポート単位で Describe 原本、表形式情報、状態、メモ、確認済み列マッピングを
蓄積する。TABULAR のみ機械変換し、それ以外は手動対応として残す。

## 2. 処理フロー

管理表を `Master` へ取り込み、`collect` で Report Describe と列情報を取得し、6 シートの
Excel とレポート別 JSON を更新する。`build-soql --apply` でドラフトを書き戻す。

## 3. 永続化

- Excel: `[FILES] EXCEL_PATH`。Master、Reports、Filters、Groupings、FieldMappings、Notes。
- JSON: `[FILES] JSON_DIR/<レポートID>.json`。Describe 原本を UTF-8 で保存する。
- CSV: `export-csv` で UTF-8 BOM 付き旧互換列を出力する。

状態は `READY / REVIEW / BLOCKED / INVALID / ERROR / PENDING`。変更履歴は Notes に残す。

## 4. SOQL 変換境界

TABULAR の基本比較、LIKE、論理フィルタを変換する。SUMMARY/MATRIX、crossFilters、
standardDateFilter、includes/excludes/within、未解決列は自動確定しない。
`LIMIT 1` 実機検証は行わない。

## 5. 構成

`main.py` は薄い入口、`src/run.py` は雛形として保持する。CLI 本体は
`src/soql_collector/`、テストは `tests/`。comken は PYTHONPATH から参照し変更しない。
