# ダウンローダーとの契約の見本

このディレクトリは、 隣のリポジトリ「ダウンローダー」（
``F:\dev\Salesforceレポートダウンローダー`` ）と soql-collector が読み手で
やり取りする **``列名の対応.csv`` のバイト単位の見本** を置く。

ダウンローダー側の ``tests/contract/`` にも同じファイルがある。 形式を
変えるときは **両方を同時に** 変えること。

中身は 「 Opportunity と Task の 4 件の解決済み列 」 の最小シナリオで、
BOM 付き UTF-8 + CRLF、 列順は ``主オブジェクト → SOQL列名`` の安定ソート、
表示名は多数決（同数なら最小管理番号）、 別の表示名は ``別の表示名あり: …``
の形式で ``備考`` にまとまる。

このディレクトリのファイルは **人が読む用ではなくバイト比較用** 。
改行コードや BOM を含めて完全に一致しなければならない。
